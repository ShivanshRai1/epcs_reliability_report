Split layouts

Split pages use two columns with optional headers. The baseline report includes several variants; when you add pages, pick the matching template in Add Page.

Other split types (add via Add Page)

  • Split Image + Image — two images side by side (not in the original baseline; create with Add Page → View more).
  • Split Content — flexible left/right blocks (text, images, links mixed). Default template when adding pages; ideal for new custom layouts.

Rich editor pages (MS WORD-like, TipTap, Excalidraw, charts) are created from templates in the Add Page dialog — see Adding new pages.

Moving between pages

At the bottom of each page:

  • Home — back to the cover
  • Index — table of contents
  • Previous / Next — move through the report in order
  • Page counter (in edit mode) — click to jump to a page number

Toolbar, edit hint & Add Page

In read mode you see navigation and Edit Page. A short hint under the toolbar reminds you that adding, deleting, and reordering pages requires edit mode.

Add Page dialog

Templates are grouped for clarity: Default templates first, then Editors, then View more for tables, split variants, links, and qualified tables.

Editing and publishing

  1. Open any page (e.g. page 5).
  2. Click Edit Page in the toolbar.
  3. Change text, tables, images, or links. Edits save as a draft in your browser.
  4. Click Publish Changes when ready — readers then see updates on Netlify.
  5. Use Live Preview to check the last published version before or after publishing.

Other tools: Add Page, Delete Page, Manage Pages (drag to reorder), Restore Original Data (resets to the baseline report — use carefully).

On image and split pages, click an image in edit mode and drag corner handles to resize. Use Display settings for font and image size steppers.

Adding new pages (all templates)

In edit mode, click Add Page, choose where to insert (before/after current page or at end), then pick a template.

Charts from data

Add a page with template Charts from data (under Editors in Add Page):

  • Enter data in the table (or use a sample preset).
  • Pick Line, Bar, or Pie.
  • Set X (labels) and Y (values); use Swap X ↔ Y if needed.
  • Use ? for axis help. Publish to show the chart to all readers.

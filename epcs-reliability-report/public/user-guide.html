Opening the report

Cover (home):
https://epcs-reliability-report.netlify.app/

Any page by number: use https://epcs-reliability-report.netlify.app/page/N where N is the page number (1, 2, 3 … 51 in the original report, or higher if you added pages).

Example — page 50:
https://epcs-reliability-report.netlify.app/page/50 (Physics based model of eGaN device gate failure mechanisms)

Moving between pages

At the bottom of each page:

  • Home — back to the cover
  • Index — table of contents
  • Previous / Next — move through the report in order
  • Page counter (in edit mode) — click to jump to a page number

Live preview (reader view)

Add ?live=1 for a simplified reader toolbar (no edit controls):

https://epcs-reliability-report.netlify.app/page/1?live=1

Editing and publishing

  1. Open any page (e.g. page 5).
  2. Click Edit Page in the toolbar.
  3. Change text, tables, images, or links. Edits save as a draft in your browser.
  4. Click Publish Changes when ready — readers then see updates on Netlify.
  5. Use Live Preview to check the last published version before or after publishing.

Other tools: Add Page, Delete Page, Manage Pages (drag to reorder), Restore Original Data (resets to the ~51-page baseline — use carefully).

On image pages, click an image in edit mode and drag the corner handles to resize. Use Display settings for font and image size steppers.

Adding new pages

In edit mode, click Add Page and choose a template. Common choices:

  • Split Content, Images, Text Only, Heading
  • View more — MS WORD-like editor, Text/Tables/Images, Excalidraw, Charts from data, split layouts, tables

Mermaid diagram template is hidden from the picker; existing Mermaid pages still open if present.

Charts from data

Add a page with template Charts from data:

  • Enter data in the table (or use a sample preset).
  • Pick Line, Bar, or Pie.
  • Set X (labels) and Y (values); use Swap X ↔ Y if needed.
  • Use ? for axis help. Publish to show the chart to all readers.
